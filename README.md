# Learning C++ 

This repository contains my early C++ exercises completed during my second year of school (Fall 2025, course: IoT-laitteiden olio-ohjelmointi). The main goal of these exercises was to learn the fundamentals of object-oriented programming and gain hands-on experience with C++ syntax, classes, objects, inheritance, and encapsulation.

While these exercises are simple, they represent the foundation of my C++ programming journey. Each exercise explores a specific concept or small project, allowing me to practice writing clean, structured, and modular code.

## What You’ll Find Here

Basic C++ syntax: (exercises 1 - 3)

Classes and Objects: Exercises focusing on creating and using classes, constructors, and member functions.

Inheritance and Polymorphism: Examples of extending classes and overriding behavior.

Encapsulation: Using private and public access specifiers, getters, and setters.

Basic Algorithms: Small programs implementing simple logic while applying OOP principles.

These exercises were primarily for learning and experimentation, so some are small programs, while others gradually build more complex behaviors as I became more comfortable with C++.

## How to Explore

Each exercise is located in its own folder with source code file(s).

## Notes

The focus here is on learning and practicing OOP concepts rather than creating production-ready code.
